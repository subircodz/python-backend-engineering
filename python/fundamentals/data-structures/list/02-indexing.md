# List Indexing

List elements can be accessed by their index.

```python
users = ["Alice", "Bob", "Charlie"]
```

| Index | Value |
|---:|---|
| 0 | Alice |
| 1 | Bob |
| 2 | Charlie |

```python
users[1]
# "Bob"
```

## Mental Model

An index identifies a **position** in the list. Python uses zero-based indexing, so the first element is at index `0`.

Indexing reads the object currently stored at that position.
